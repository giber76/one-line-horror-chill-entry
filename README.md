# One Line, One Chill

Entry for [One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488)
on make.fun — one sentence of horror, under 200 characters, that has to
frighten a reader in one breath.

## The line (78 characters)

> At 3am the baby monitor played my own voice singing a lullaby I never learned.

## Why this sentence

- **Frightening first:** something in the nursery is wearing your voice, and
  the dread outlasts the line — it knows a song you never learned.
- **Vivid:** a concrete domestic image a reader can see and hear at once —
  3am, the baby monitor, your own voice, a lullaby.
- **Original:** no mirror, no doll, no basement; the horror is imitation,
  not a monster jumping out.
- **Crafted:** the sentence builds — time, place, voice — and the last word,
  "learned", lands the impossibility.

## How it runs

`main.ts` (Node 22, standard library only) writes the sentence to
`/output/entry.txt`. Run locally with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
